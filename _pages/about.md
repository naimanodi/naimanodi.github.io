# Recent Updates

### Master's Thesis
I am currently working on my Master's thesis, which focuses on refining sentiment analysis models for dynamic, streaming user reviews. My research aims to improve data synthesis reliability by replacing random sampling with an attention-based selection model that prioritizes temporal relevance and sentiment similarity. To address LLM hallucinations, I am developing an automated validation pipeline that integrates a knowledge-graph-enhanced LLM.
